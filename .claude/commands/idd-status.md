# IDD Status

Show the current state of all active IDD features.

Read docs/intents/active/ and list every intent statement found.
For each file report:
- Feature name (from the filename)
- Version (from the # heading in the file)
- Number of open questions (count items in §Open Questions)
- Whether a tasks.md exists for this feature

Output as a table:
Feature | Version | Open Questions | Tasks file
